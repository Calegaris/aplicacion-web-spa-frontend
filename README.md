# Burger House — Frontend

SPA de carrito de compras para una hamburguesería. Frontend construido con React, TypeScript y Tailwind CSS.

## Stack

- **React 19** + **TypeScript**
- **Vite** (build tool)
- **React Router v7** (routing)
- **Axios** (HTTP client)
- **Zustand** (state management)
- **Tailwind CSS v3** (styling)

## Desarrollo

```bash
pnpm install
pnpm dev
```

Abre `http://localhost:5173`

## Build

```bash
pnpm build
```

## Estructura

src/

├── api/          → Llamadas HTTP al backend

├── components/   → Componentes reutilizables

├── context/      → Context API

├── hooks/        → Custom hooks

├── layouts/      → Layouts (navbar, sidebar)

├── pages/        → Páginas/vistas principales

├── router/       → Configuración de React Router

├── types/        → Tipos TypeScript

├── utils/        → Funciones auxiliares

└── styles/       → Estilos globales
